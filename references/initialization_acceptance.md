# 初始化验收

验收区分结构、真实材料与跨对话接续，不能以目录已生成推断长期可用。

状态仅用：通过（有证据）、待修正（有具体问题）、未验证（缺少操作或材料证据）。

## 结构验收：前五项

1. **文件与目录**：三件套存在可读，目录符合用户确认方案；没有静默覆盖旧文件。
2. **个性化与清洁度**：无未填占位符、他人信息、虚构项目或预设的私人习惯；未知明确标注。
3. **三件套分工**：地图、协作与操作各司其职；AGENTS 实际要求加载根规则；日常更新不依赖重新调用初始化 Skill；无互相冲突或大段重复。
4. **地图与恢复入口**：实际目录、相关主题入口与链接可找到；用户知道新对话如何恢复。写了说明不代表已实际跨对话测试。
5. **安全与恢复边界**：授权按范围、材料指令不执行、敏感信息可拒绝留存；覆盖前差异及恢复办法明确；不承诺本地存储等于模型离线。

前五项全通过才开始正式材料写入；待修正时先说明差异。修正已在原授权内则完成并复验，超范围再确认。

## 真实材料验收

选真实且获准的材料，走通读取、增量判断、确认、写入与读回：

- 未删除用户原件；仅在获准留存时保存原文副本。禁止留存时验证没有新增副本，只用获准的来源或说明追溯限制。未读或未处理部分明确可见。
- 确认事实、推断、冲突和未知没有混写。
- 当前状态只在一个主文件维护，日期记录仅摘要和来源。
- 实际写入前已复核目标未被他人改动，或已重新比较并按需要获得确认。
- 完成、取消或替代有日期与依据，原独有信息不丢。
- 能从目标文件回答背景、当前状态、最近变化及来源。
- 用户知道下一份材料放在哪里、如何处理。

可用同一份材料再走一次只读判断，确认不会建议重复新建记录。不能凭流程文本宣称防重复已验证。

## 跨对话接续

条件允许时在一个不继承本轮聊天的新对话，只提供工作目录和一个真实问题，验证 AI 实际读取三件套及主题主文件后能接续。

没有独立新对话可测试时标“未验证”，交付恢复口令；不能用同一对话里的复述当作跨对话成功。

| 安全与恢复边界 | 通过 / 待修正 / 未验证 | 权限与恢复办法 |
| 真实材料闭环 | 通过 / 待修正 / 未验证 | 材料与读回结果 |

仅结构通过：结构初始化完成。
真实材料也通过：可开始真实使用，注明跨对话是否验证。
缺真实材料：真实闭环未验证，不阻塞结构交接，不造样例冒充真实材料。
长期效果：由用户真实使用后的反馈判断，单次测试不等于长期验收。
